# Январь 2027 — Java как язык-мишень

Назад к [фазе A](../phase-a.md) · [план](../../appsec-plan.md)

## Цель месяца

Научиться **читать** чужой Spring Boot проект и видеть в нём опасные места. Писать на Java не надо.

## Темы

- [Десериализация и XXE](../../12-deserialization/deserialization.md)

## По неделям

1. Синтаксис как «C# с другими именами»: типы, generics, коллекции, исключения
2. Spring Boot: аннотации, DI, контроллеры, Spring Security
3. JPA/Hibernate, JDBC и где там появляется SQLi
4. Небезопасная десериализация и XXE — на Java они выглядят каноничнее всего

## Надстройка этого месяца

Надстройка уходит целиком под Java. Ядро (лаба + конспект + коммит) продолжается без изменений, но лабы берутся из уже пройденных классов на уровне practitioner — новых тем в этом месяце не открываем, иначе Java не влезет.

## Что должно появиться к концу

- Берёшь незнакомый Spring Boot проект с GitHub и за час называешь три места, где стоит присмотреться
- Конспект по небезопасной десериализации с разбором кода
- C# из первого курса частично восстановлен побочным эффектом
