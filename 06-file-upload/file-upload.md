# File upload

Тема фазы A · по плану — [октябрь 2026](../plan/months/2026-10.md) · назад к [плану](../appsec-plan.md)

## Что это

Приложение принимает файл и где-то его сохраняет. Опасность не в самом файле,
а в сочетании трёх вещей: что записали, куда записали и **как это потом отдаётся**.
Уязвимость обычно живёт в третьей.

## Что уметь к концу темы

- Разбирать загрузку на три отдельных вопроса: тип, путь, отдача
- Знать, почему проверка расширения и Content-Type не работает
- Объяснить, почему безопасная загрузка — это в первую очередь вопрос хранения

## Подтемы

- [ ] Обход проверки типа файла
- [ ] Исполнение загруженного файла
- [ ] Загрузка вне целевого каталога
- [ ] Обход через заголовки и двойные расширения

Точный список лаб бери на сайте PortSwigger — он меняется. Здесь подтемы, а не оглавление.

## Как чинится в коде

Имя файла придумывает сервер, а не пользователь. Каталог загрузок — вне корня веб-сервера
и без права на исполнение. Тип проверяется по содержимому, а не по расширению
и не по `Content-Type` — их обоих задаёт клиент.

Отдача — отдельным обработчиком, который сам выставляет `Content-Type`
и `Content-Disposition`, а не статикой напрямую.
