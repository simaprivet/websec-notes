## Что из этого важно помнить

- **`system_prompt` против `prompt`.** Первый — правила и формат, второй — данные для обработки.
  Проверено ошибкой: пока в `prompt` уходил текст про `sys.argv` вместо содержимого файла,
  модель принимала его за задание себе
- **Ответ — структура, а не строка.** Текст собирается из блоков `message.content`,
  текстовых блоков может быть несколько
- **Ошибки печатаются в `sys.stderr`.** Тогда при перенаправлении вывода в файл туда попадёт
  результат, а жалоба останется на экране
- **Трейсбека недостаточно.** Он написан для того, кто читает код: показывает, *где* сломалось,
  а понятное сообщение — *что делать*. Плюс падение даёт неверный код возврата
